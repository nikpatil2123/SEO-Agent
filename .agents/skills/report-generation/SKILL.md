# Report Generation

## Initial report (before implementation)

Required sections:
1. Executive summary and scope.
2. Business/product understanding, including confirmed facts and unknowns.
3. Website inventory and baseline audit.
4. Competitor landscape: business/search/content/product competitors.
5. Top-five organic result analysis for each priority query, with locale, device, source and timestamp.
6. SEO findings and strategy.
7. GEO findings and strategy.
8. AEO findings and strategy.
9. Complete content proposals and metadata.
10. Technical/schema recommendations.
11. UI preservation and visible-content consent register.
12. Baseline SEO/GEO/AEO scores out of 10, criterion breakdown, evidence coverage and confidence.
13. Versioned implementation plan with priorities, effort, risk, dependencies and validation.
14. Explicit approval question.

End with:
"Would you like to approve implementation of plan [ID/version]? No website changes have been made. Visible text changes, UI/design changes and production deployment require separate approval."

## Final report (after implementation)

Required sections:
1. Executive summary.
2. Approved plan version and consent records.
3. Before/after SEO, GEO and AEO scores out of 10 and point changes.
4. Criterion-level score breakdown and assessed coverage.
5. Before/after technical and content findings.
6. URLs and files modified.
7. Exact approved content changes or links to diffs.
8. UI preservation/visual regression results.
9. Tests and validation evidence.
10. Staging and production deployment status.
11. Failed, incomplete, rejected and deferred items.
12. Remaining risks and limitations.
13. Monitoring plan and recommended review dates.

## Evidence and honesty

- Cite/identify sources for competitor and external research.
- Record dates and query context.
- Distinguish observed facts, customer-provided facts, estimates and hypotheses.
- Never fabricate scores, rankings, traffic, citations, test results or deployment status.
- Use "not measured" when no reliable data exists.
- State whether report scores measure implementation readiness or observed search performance.
- Include a clear note that score improvements do not guarantee ranking or traffic improvements.

## Formats

Markdown is mandatory. HTML/PDF may be generated if the environment supports reliable file creation. Ensure all formats contain the same figures and caveats.
